# 靜宜觀光島 V2.0：尋貓集章與探險護照

## 已完成功能
- 沿用 V1.3 簡潔環島步道、九大建築、日夜切換、相機操作與系網連結。
- 十隻貓咪沿環道散步、休息、對話（使用最新提供的 `cats(3).js` 原始台詞）。
- 初次點擊每隻貓自動集章，重複點擊不重複計數。
- 右上角「護照」查看十隻貓的圖鑑、集章進度與尋貓里程碑稱號。
- 點擊貓咪可選擇「再聊一句」或「尋寶線索」，線索可前往原本建築介紹。
- 重新整理頁面後仍保留尋貓紀錄（localStorage，僅該瀏覽器）。
- 可經確認後手動清除尋貓紀錄。

## 尚未實作（下一階段）
- 九大地標正式尋寶小遊戲及地標徽章：V2.1。
- 三階段正式獎勵圖卡與完整電子紀念證書：V2.2。
- 本版 3、7、10 隻貓的稱號屬於「尋貓里程碑」，**不是**先前規劃的 3+1、7+5、10+9 完整遊戲成就。

## 修改與部署
請上傳本專案資料夾內容至 GitHub Pages repository 根目錄；保留 `index.html`、`css`、`js`、`data` 相對路徑。
`js/cats.js` 和 `data/locations.js` 採用使用者上傳版本，請勿以舊版覆寫。
Three.js 以 CDN 載入，需網路連線。若舊畫面快取未更新，請強制重新整理。

## 已知限制
本機進度不能跨裝置同步，清除瀏覽器網站資料也會移除進度；瀏覽器停用或限制儲存時可能無法保存。
需在部署後實測 3D 渲染、滑鼠/觸控選取、貓咪路徑與各視窗顯示效果。
