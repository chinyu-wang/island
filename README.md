# 靜宜觀光島 V2.2 — 十貓 × 九地標 × 限定獎勵

純靜態網站，放到 GitHub Pages 的儲存庫根目錄即可，需連線載入 Three.js CDN。

## V2.2 新功能
- 右上角「🎁 獎勵」收藏室；護照內亦有入口。
- 收集 3 貓＋1 地標：小橘迎賓圖卡。
- 收集 7 貓＋5 地標：三貓探險隊圖卡。
- 收集 10 貓＋9 地標：十貓全員集合圖卡＋探險紀念證書。
- 所有圖卡與證書由 `js/rewards.js` 直接使用 Canvas 產生 PNG，可下載。證書可自填暱稱（不會上傳）。
- 保留 V2.1.1 既有音效、音樂、地標小遊戲與 10 貓集章。
- 沿用 V2.1 進度 localStorage key `pu-tourism-island-v2-progress`，無需重新集章。

## 測試建議
1. 開啟「獎勵」確認 4 個獎勵預設鎖定，且能顯示尚缺的印章數量。
2. 取得 3 貓／1 地標，開啟獎勵，下載小橘圖卡。
3. 達成 7／5、10／9 後，測試另外的圖卡及證書下載。
4. 輸入暱稱確認證書更新，並檢查 Chrome/手機上的下載。
5. 重新整理，確認已完成紀錄依然保留；測試音效與背景音樂切換。

## 注意事項
- 獎勵圖片是 Canvas 原創插畫（依現有貓咪配色繪製），不依賴外部圖片來源。
- 電子證書為遊戲紀念性質，非正式學習認證。
- 沒有伺服器與帳號，紀錄只在同一瀏覽器、同一網站來源保留。
