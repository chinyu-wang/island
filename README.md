# 靜宜觀光島 V2.1 — 十貓尋寶 × 九大地標闖關 × 聲音

靜態網站，適用 GitHub Pages。解壓後將本資料夾的 `index.html`、`js/`、`css/`、`data/` 放到 repository 根目錄，無須 npm 或後端。

## 新功能

- 九個地標都新增「開始地標挑戰」。包含情境選擇、配對問答、翻卡、多選與方向探索；完成後取得地標徽章。
- 尋貓與地標進度整合至原 V2.0 探險護照；同一瀏覽器的既有十貓紀錄保留。
- 原創 Web Audio 程式合成背景音樂與音效，**音樂和音效可分開開關**，預設皆關；首次需使用者點擊，尊重瀏覽器禁止自動播放的限制。
- 不含外部音樂檔或授權風險。Web Audio 不支援時畫面及遊戲仍應運作。
- 你修改過的 `data/locations.js` 與 `js/cats.js` 全部保留，未修改貓咪日常對話。

## 資料真實性

榮耀殿堂、系友故事村先採**探索興趣方向**的互動，不杜撰獲獎者、系友身分或真實事蹟；詳細內容由相應官網連結提供。等取得正式案例與系友公開同意後，可升級為真實故事挑戰。教師專長也未編造特定師資配對。課程等內容可依後續官網資料校正。

## 測試建議

1. 開始探索後測試背景音樂與音效的獨立開關，重新整理後保存開關偏好（再次點擊才允許播放）。
2. 找到貓咪集章、刷新網頁驗證舊進度。
3. 九棟建築逐一點擊闖關：答錯再試、翻卡、興趣選擇、多選並完成。
4. 護照地標徽章應正確反映 0–9 個完成數，刷新後仍在。
5. 用手機測試關卡視窗捲動、貓咪點選與響應式版面。

## 開發注意

場景依賴 Three.js CDN，開啟網頁時需要連網，建議透過 GitHub Pages 或本地 HTTP 伺服器測試，不要使用 `file://` 路徑。


## V2.1.1 聲音修正說明

底部「♫ 音樂關」點一下切換成「♫ 音樂開 ✓」並立即播放旋律；再點一下關閉。
底部「♪ 音效關」點一下切換成「♪ 音效開 ✓」，同時播放短促的確認音；之後點貓咪、取得徽章等會有提示音。兩者獨立控制，設定會留存在瀏覽器。
瀏覽器需在使用者點擊後才允許聲音。如果已開啟但沒有聲音，請確認瀏覽器分頁未靜音、裝置輸出音量及耳機。此版提高背景音量、立即靜音已排程音符，並增加按鈕狀態提示。
